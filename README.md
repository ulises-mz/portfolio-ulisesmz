## 📖 Overview / Descripción

**EN** — Personal portfolio of Ulises Méndez Z. Single-page site showcasing projects, skills and contact, built with React 19 + Vite and styled with TailwindCSS. Mobile-first and SEO-ready (Open Graph + Twitter Cards).

**ES** — Portafolio personal de Ulises Méndez Z. Sitio de una sola página que muestra proyectos, habilidades y contacto, hecho con React 19 + Vite y estilado con TailwindCSS. Mobile-first y optimizado para SEO (Open Graph + Twitter Cards).

## ✨ Features / Características

- ⚡ **Fast** — Vite build with optimized assets / Build con Vite y assets optimizados
- 📱 **Responsive** — Mobile-first design / Diseño mobile-first
- 🔍 **SEO-ready** — Open Graph, Twitter Cards, semantic HTML
- 🎨 **Modern UI** — Clean, minimal TailwindCSS design / UI moderna y minimalista

## 🛠️ Tech Stack

`React 19` · `Vite 7` · `TailwindCSS 3` · `JavaScript (ES Modules)` · `ESLint`

## 🚀 Run locally / Ejecutar localmente

```bash
git clone https://github.com/ulises-mz/portfolio-ulisesmz.git
cd portfolio-ulisesmz
npm install
npm run dev      # http://localhost:5173
npm run build    # production build
npm run preview  # preview the build
```
