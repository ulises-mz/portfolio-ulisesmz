# Imágenes del Portfolio

## Foto de Perfil

**Archivo:** `profile.png` ✅

### Especificaciones recomendadas:
- **Formato:** JPG o PNG
- **Tamaño:** 800x800px mínimo (cuadrado)
- **Peso:** Menos de 500KB para mejor rendimiento
- **Fondo:** Preferiblemente con fondo oscuro o neutro para mejor contraste

La imagen se mostrará en formato hexagonal en la sección "Sobre Mí" con efectos de escaneo y bordes neón animados.

Si no hay imagen, se mostrará el placeholder "UM" como fallback.

### Especificaciones generales para mockups:
- **Formato:** PNG preferido (para transparencias) o JPG
- **Aspect Ratio:** 16:9 (horizontal)
- **Tamaño:** Entre 1280x720px y 1920x1080px
- **Peso:** Menos de 800KB cada una
- **Calidad:** Alta resolución para pantallas retina
- **Contenido:** Screenshots o mockups de las aplicaciones/sitios

### Efectos aplicados:
- Hover: Escala de imagen al 105%
- Bordes neón con glassmorphism
- Fallback a gradiente si la imagen no carga
- Transiciones suaves

**Nota:** Si una imagen no se encuentra, se mostrará un fallback con gradiente y el nombre del proyecto.
